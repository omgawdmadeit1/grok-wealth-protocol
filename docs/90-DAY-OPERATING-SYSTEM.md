# 90-day operating system
Clock starts the day this file is committed. One workstream per week. Family time is scheduled first.

## Weekly rhythm (low-physical)
- **Mon 45 min:** books + benefits. Plaid or manual. Anything that hit a bank.
- **Tue 90 min:** one application (grant, PASS section, unclaimed claim, research email).
- **Wed 0 min work if possible:** memory block. Walk, meal, photos, no laptop.
- **Thu 90 min:** product/catalog or research partnership, not both.
- **Fri 30 min:** supervisor review. Kill anything that did not file or ship.
- **Sat/Sun:** family default. Work only if a deadline is real (SSA, grant portal).

Travel: one in-state overnight in days 45–75 (Helen / Atlanta aquarium / farm-adjacent — cheap, memorable). Budget from unclaimed or a single product sale, never from SSI.

## Days 1–7 — floor
- [ ] Open `finance/TRUTH_LEDGER.md` and enter *actual* balances only.
- [ ] missingmoney.com + Georgia unclaimed + every state ever lived. File, don’t “oracle.”
- [ ] List every benefit: SSI amount, Medicaid, SNAP, any child support, any 529.
- [ ] Book (or request digital) a PASS conversation with SSA / a Georgia PASS specialist. Draft goal: self-employment that is laptop/voice, family-supporting, and names a vehicle or ergonomic setup only if the counselor agrees it is a PASS-able expense.
- [ ] 90-minute attorney consult on revocable trust + term life + guardianship for the minor. Use the July 2026 trust notes as a *brief*, not as a legal document.
- [ ] Put four Wednesday memory blocks on a shared calendar.

## Days 8–30 — one lane
Pick **one** primary lane. Park the rest.

**Lane A (default): Georgia capital + PASS.**  
GVRA intake, OneGeorgia / rural small-business technical assistance via SBDC, DOBE only if certification is actually in reach. Digital packets. No phone marathon if an agent can pre-fill.

**Lane B: catalog.**  
Unblock or re-release existing music/visuals. One distribution path. Teen can do metadata. No new brand.

**Lane C: research partnership.**  
Send the three emails in `docs/UHI-UBI-RESEARCH.md`. Measure replies, not vibes.

## Days 31–60 — proof
- First real dollar that is either non-countable or PASS-parked.
- 529 opened and a first contribution, even $25, if cash exists.
- Trust engagement letter signed or a written reason why not.
- If Lane C replied: scope a one-page study with a PI. If silence: stay on A/B.

## Days 61–90 — decide
Keep the lane that produced a filing or a dollar. Kill the others in writing.

Success at day 90 is **not** $100k. Success is:
1. Benefits still intact.
2. Books that match a bank.
3. One live income or capital process.
4. Family calendar that actually happened.
5. A written 12-month plan that a spouse can run if the architect has a bad pain week.

## Supervisor kill questions
Ask every Friday:
- Did this protect SSI?
- Did this file something?
- Did this put cash in a real account?
- Did this create a memory?
If four nos, it dies.
